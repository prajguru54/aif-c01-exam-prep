Domain 1: AI and ML fundamentals (20%)

Nesting

AI contains ML contains deep learning contains GenAI. Agentic AI = GenAI + planning + tools + autonomy.

Fit

  • Underfit = high bias: poor on train and test.
  • Overfit = high variance: great on train, poor on new data.

Learning types

  • Supervised: labels (classification, regression)
  • Unsupervised: no labels (clustering)
  • Reinforcement: reward, trial and error (RLHF)
  • Self-supervised: LLM pre-training

Technique by output

  • Number = regression
  • Label = classification
  • Group = clustering
  • Future values = forecasting

Do NOT use ML when: exact guaranteed outcome, fixed formula, no data, cost exceeds benefit. Traditional ML over FM: regulated, must explain, structured data, deterministic, cheap per call.

MLOps: experimentation, repeatable pipelines, scalable systems, technical debt, production readiness, monitoring (data drift, concept drift), retraining. Pipeline: collect, prepare, train, evaluate, deploy, monitor, loop.

Domain 2: GenAI fundamentals (24%)

Vocabulary

  • Token: unit of processing and billing
  • Chunking: split docs for retrieval
  • Embedding / vector: numeric meaning, closeness = similarity
  • Transformer: LLM architecture (attention)
  • Diffusion: image generation from noise
  • Multi-modal: several data types

FM lifecycle

Data selection, model selection, pre-training, fine-tuning, evaluation, deployment, feedback.

Token cost levers

  • Shorter prompts, capped output
  • Smaller model
  • Prompt caching (repeated prefix)
  • Batch (discount, offline)
  • Provisioned Throughput (steady heavy load)

Agentic terms

  • MCP: standard way to connect agents to tools and data
  • Short-term vs long-term memory
  • Orchestration, supervisor pattern
  • Context engineering = everything in the context window

GenAI weaknesses: hallucination (RAG, grounding check), inaccuracy, low interpretability, nondeterminism (lower temperature). Metrics: conversion rate, efficiency, ARPU, customer lifetime value, ROI, accuracy.

RAG flow

Docs, chunk, embed, vector store. Query: embed question, similarity search, add chunks to prompt, FM answers with citations. Managed by Bedrock Knowledge Bases.

Vector stores named

  • OpenSearch Service: hybrid search at scale
  • Aurora / RDS PostgreSQL: pgvector
  • Neptune: graph, relationships (GraphRAG)

Prompting

  • Zero-shot 0 examples, single-shot 1, few-shot several
  • Chain-of-thought = step by step reasoning
  • Negative prompt = what to avoid
  • Prompt Management: variables, versions, rollback

Prompt risks

  • Exposure: leaks prompt or data
  • Poisoning: bad source data
  • Hijacking: injection overrides instructions
  • Jailbreaking: bypass safety rules

Domain 4: Responsible AI (14%)

Features

Fairness, bias mitigation, inclusivity, robustness, safety, veracity, privacy, transparency, accountability.

Bedrock Guardrails

  • Content filters and prompt attack
  • Denied topics, word filters
  • Sensitive info (block or mask PII)
  • Contextual grounding check
  • Automated Reasoning checks

Legal risks

IP infringement, biased outputs, loss of trust, end-user harm, hallucinations.

Find bias

Label quality review, subgroup analysis, human audits, ongoing monitoring. Dataset: diverse, curated, balanced.

TransparentOpaque
Linear or logistic regression, decision tree, open modelsDeep networks, closed LLMs
Auditable, explainable, maybe less accurateAccurate, hard to explain
Tools: SageMaker Model Cards (document intended use, data, risks). AWS AI Service Cards. Model Evaluation (toxicity, robustness). Human-centered: disclose AI, show reasons, feedback, human in loop. Trade-offs: interpretability vs performance, transparency vs safety and IP. Green: smallest model that works, reuse models.
