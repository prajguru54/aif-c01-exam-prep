# AIF-C01 Exam Prep

Study repository for the **AWS Certified AI Practitioner (AIF-C01)** exam.

Companion to the professional-level [Bedrock / AIP-C01 repo](../bedrock/).

## Exam at a glance

| | |
|---|---|
| Scored questions | 50 (plus 15 unscored) |
| Passing score | 700 / 1000 |
| Question types | Multiple choice, multiple response |
| Guide version | 1.2 (October 29, 2026) |

| Domain | Weight |
|---|---|
| 1. Fundamentals of AI and ML | 20% |
| 2. Fundamentals of GenAI | 24% |
| 3. Applications of Foundation Models | 28% |
| 4. Guidelines for Responsible AI | 14% |
| 5. Security, Compliance, and Governance for AI Solutions | 14% |

## Contents

- [`exam_guide.md`](./exam_guide.md): official exam guide ([PDF](./exam_guide.pdf))
- [`docs/domains/`](./docs/domains/): one study note per domain
- [`docs/concepts/`](./docs/concepts/): cross-cutting concept docs
- [`labs/`](./labs/): small scripts that make a concept concrete
- [`AGENTS.md`](./AGENTS.md) and [`my_background.md`](./my_background.md): instructions for coding agents

## Suggested order

Domains 1 and 4 first (new vocabulary), then 2 and 3 (the heaviest, 52% together, and the
closest to existing GenAI experience), then 5.
