- **DevOps:** Docker, Git, basic cloud infrastructure

## 2. Current Goal: AWS Certified AI Practitioner (AIF-C01)

I am studying for AIF-C01 after (or alongside) the AIP-C01 track in the `../bedrock` repo.
I know GenAI well from the practical side. What I need is:

1. The **formal vocabulary** the exam uses (classical ML terms, metrics, learning types,
   bias and variance, and so on), which I may know only informally.
2. **AWS service selection**: which managed AI service or Bedrock feature fits a scenario.
3. **Responsible AI, security, compliance and governance** concepts and the AWS services behind them.
4. **Exam technique**: reading scenario questions, spotting keywords, eliminating distractors.

## 3. Preferred Learning Approach

- Concise, accurate notes over long courses.
- Analogies to backend and GenAI concepts I already know.
- Side-by-side comparisons ("when to use X vs Y").
- Scenario questions with explanations of why each wrong option is wrong.
- Small hands-on labs only where they make a concept concrete.

## 4. Guidance for Coding Agents

- Treat me as an experienced developer and an AWS and classical-ML beginner.
- Skip basic Python, REST, Docker and LLM explanations.
- Explain AWS terminology and classical-ML terms (precision, recall, overfitting,
  supervised vs unsupervised) clearly the first time they appear.
- Keep to what the exam tests. Say so when something is beyond exam depth.
- Distinguish "know this for the exam" from "know this for real-world practice".
